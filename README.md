# DefiWave

Real-time data processing engine for blockchain-based applications, utilizing auto-scaling architecture and secure data gateway.

The key benefits of using DefiWave include:

- Real-time data processing engine for
- blockchain-based applications, utilizing auto-scaling architecture
- and secure data gateway

## Technology Stack

- typescript

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiWave.git`
2. `cd DefiWave`
3. Install in editable mode: `pip install -e .`

## Configuration

DefiWave is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
